# Effemeral documentation

Effemeral is a private, album-first catalogue and playlist curator. These guides describe behavior that exists in the application today.

- [Application guide](application.md) — pages, catalogue browsing, playlists, recommendations, and the normal user workflow.
- [CLI guide](cli.md) — imports, enrichment, status, retries, and Spotify playlist sync from Artisan.
- [Integrations guide](integrations.md) — what Last.fm, Spotify, and MusicBrainz contribute and how their data is treated.
- [Development guide](development.md) — Docker, configuration, checks, migrations, branches, and pull requests.

The root README remains the short public-facing introduction. These guides are for local development and day-to-day use.
